Lane Math — Phase 5F: audio. No visual change, so no screenshots this batch.
Audio cannot be photographed, so everything below is instrumented and measured.

1. SYNTHESIS — procedural, no audio files shipped (confirmed: 0 in dist).
   Every voice is filtered noise plus low detuned oscillators. Nothing is
   sampled, nothing rings, and no voice uses an interval that could be heard as
   a melody.

   click      tap a tile      bandpass noise 1500-2900Hz (Q 3.5), 28ms, plus a
                              320-540Hz triangle body. Centre frequency is
                              driven by the TILE VALUE, so the board sounds like
                              a set of distinct objects rather than one button.
   knock      place in slot   9ms lowpassed transient + 190Hz triangle, 130ms,
                              then a quieter 150Hz second contact at 42%: the
                              piece lands, rocks once, is still.
   knockSoft  return          no transient at all, 45ms attack, 155Hz, 160ms.
                              The MISSING edge is what reads as reversed —
                              nothing is literally played backwards, which would
                              sound like an effect rather than a material.
   thunk      commit correct  30ms lowpassed thump + 96Hz sine, 420ms tail, with
                              a fifth above for body. The heaviest sound in the
                              game, arriving into the silent hit-stop gap.
   scrape     commit wrong    lowpassed noise sliding 620Hz -> 300Hz, 200ms,
                              18ms attack. NO oscillator at all, so nothing is
                              pitched and nothing can be heard as a wrong note.
   tear       transform       bandpass noise 900 -> 2600Hz (Q 1.4), 190ms, and
                              no wooden body. The only voice without one, so a
                              transform can never be mistaken for a binary move.
   fail       failure         68Hz sine, 900ms, lowpassed to 400Hz, and the
                              quietest pitched voice. The board already said it.
   star       level complete  6ms transient + 220Hz triangle lowpassed hard at
                              1100Hz, 220ms. Fired one per star as it SEATS.
                              The three pitches move about a tone in total, so
                              it counts a tally rather than resolving a fanfare.

   All pitched voices are detuned +/-12% per trigger, so the tenth knock in a
   row still sounds like an object and not a repeated file.

2. TAP LATENCY — audio on vs muted. UNCHANGED.
     audio on   median 9.6ms
     muted      median 9.5ms
   400 samples, INTERLEAVED: the mute state alternates every sample, because a
   straight A-then-B run gave audio-on 1.4ms and muted 2.5ms — muted measuring
   SLOWER, which is causally impossible and showed the run was drifting. The
   0.1ms difference is noise.

   SEPARATE FINDING, NOT AUDIO — latency degrades with use.
   Median tap cost against taps taken, on a fresh page:
     100 taps 2.8ms   200 6.0   300 10.4   400 14.4   500 19.4   600 23.4
   Linear, and present with audio muted, so audio is not the cause.
   TWO HYPOTHESES TESTED AND BOTH FALSIFIED:
     - undestroyed display objects on redraw: destroying every child each frame
       did not change the slope at all (and cost more). Reverted rather than
       left in as an unproven fix.
     - telemetry O(n^2) writes: only 2 events are recorded per 100 taps, and
       clearing the log did not help.
   Cause still unknown. Flagged for Phase 6; it is a real problem — 23ms taps
   after 600 interactions is below 60fps responsiveness — but it is not this
   session's and I will not guess at it in a commit message.

3. NO SOUND DURING THE HIT-STOP — proven, not asserted.
   Sampled six times inside the hold at a slowed clock:
     holding true, cues []   x6      then on release: ["thunk"]
   It is structural rather than timed: cues are produced from the ADOPTED
   state, and the hold defers adoption, so the thunk cannot physically be made
   before the beat has passed. A unit test pins the two predicates together.

4. RETRY STILL EMITS EXACTLY ["render"] — the existing guarantee test passes
   unchanged. Audio added nothing to that path, and restart is SILENT as well
   as instant: a rewind is the harshest moment in the game and does not need
   the game commenting on it.

5. NOTHING PLAYS WHILE IDLE — two seconds untouched, zero cues. There is no
   ambience and no idle loop; the game is silent until the player acts.

MUTE — persisted in the save, default ON (unmuted). Additive field with a safe
default, so no schema bump: migrate() already coalesces every field and a save
written before audio reads as unmuted. Verified: setting it writes muted:true to
lane-math.save.v1, and nothing plays while set.

TWO DEFECTS FOUND BY THE INSTRUMENTATION
  a) RETURNS DOUBLE-KNOCKED. The cue fired when the slot emptied AND again when
     the travelling token landed. Placement genuinely wants two sounds — a click
     for the finger, a knock for the piece arriving 260ms later — and the return
     had followed it by reflex. Now one sound, with a test.
  b) A MID-LEVEL RESTART WAS NOT DETECTED AS A REWIND. Restarting before
     anything is consumed produces a state identical to the previous one except
     the equation row emptying — which is byte-for-byte what returning a tile
     looks like. It was animating tiles flying home and sounding a knock the
     player never earned. State-diffing genuinely cannot separate them, so the
     Director now counts its own rewinds and ViewState carries `run`.

KNOWN GAP, FOLLOWING THE BRIEF LITERALLY: tapping a binary OPERATOR makes no
sound. The sound map lists "tap a pool tile" and not "tap an operator", so it is
silent by omission rather than by decision. Say if it should have a voice.
