--------------------------------------------------------------------------------
WHAT I CHANGED BEYOND THE SEVEN
--------------------------------------------------------------------------------

  * `button` gained a material FACE. The first commit-key attempt added the
    brass as a sibling behind the button's own fill, so it never drew — the key
    photographed as flat navy. As a face it is painted inside the component and
    sinks with the press.
  * The status band's two rows are derived in `statusRows` instead of the
    literals +8/+44/+46. The map button and the mode chips were 10px BELOW the
    60px band they belong to; invisible on bare desk, obvious on a tray.
  * Developer chrome (the meta line, the build label and its long-press
    telemetry export) is behind `debugChrome()` AND now sits below the band, so
    it cannot displace a designed row.

HARNESS
  * `shot.mjs` gained a `SHOT_SCREEN=armed` driver that stages a legal
    expression, so the commit key's GOLD state is photographable. Every board
    shot before this one showed the disarmed key — the state §9.6 actually
    specifies had never been reviewed.
  * out-of-lives has to be shot at 2-08 or later. Lives are absent before that
    by §7.6, so a 2-01 seed with zero lives photographs an ordinary board.
  * The hint shop needs `furthestReached >= 3-06`, which means a save ENTRY at
    3-06, not clears up to 3-05.

  * The FAILURE modal needs the warning overridden AND the play continued:
    overriding takes the fatal move but the level is not lost until the lane
    cannot advance (§9.4). `SHOT_SCREEN=failed` now drives that loop. Shot at
    2-05 — at 1-03 `playIntoFailure` photographs the CLEARED panel, because the
    tutorial tier is trapless by §8.3 and cannot be lost.
